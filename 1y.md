# Progression annuelle — 1re année

## Objectifs de fin d’année

À l’issue de l’année, les étudiants doivent être capables de :

- créer un site statique simple et responsive en HTML et CSS ;
- réaliser un portfolio/CV personnel de une à trois pages ;
- développer une application web interactive simple avec JavaScript ;
- lire une spécification et respecter un protocole de communication imposé ;
- créer une interface de messagerie temps réel connectée à un serveur WebSocket ;
- explorer et présenter des données avec Python, Pandas, Marimo et PyChart ;
- développer un petit site dynamique en PHP procédural typé ;
- identifier et appliquer les premières notions de programmation orientée objet.

Le rythme privilégie des démonstrations courtes, de la pratique guidée, puis des temps de consolidation et de correction collective adaptés à un groupe débutant.

---

# Semestre 1 — Fondamentaux du web et JavaScript (environ 30 h)

## Bloc 1 — HTML et CSS : portfolio/CV (10h)

**Objectif :** concevoir et publier un site portfolio/CV personnel simple, composé d’une à trois pages.

| Séance / activité | Description |
|---|---|
| **Découvrir le Web et HTML** | Comprendre le rôle du navigateur, du HTML et du CSS ; créer une première page structurée avec titres, paragraphes, listes et liens. |
| **Structure d’un CV en HTML** | Utiliser les balises sémantiques (`header`, `main`, `section`, `footer`) pour organiser les rubriques d’un CV. |
| **Médias et navigation** | Ajouter image, liens internes/externes et navigation entre plusieurs pages ; vérifier l’accessibilité de base. |
| **Premiers styles CSS** | Appliquer couleurs, polices, espacements, bordures et sélecteurs ; créer une charte graphique simple. |
| **Mise en page avec Flexbox** | Organiser l’en-tête, les colonnes et les cartes de compétences ; distinguer contenu HTML et présentation CSS. |
| **Site responsive** | Adapter le portfolio aux écrans mobile et ordinateur avec media queries ; tester dans les outils du navigateur. |
| **Atelier portfolio/CV** | Finaliser un site de une à trois pages, corriger la structure et présenter son travail à un pair. |

---

## Bloc 2 — Premiers programmes JavaScript : Jeu du pendu (10 h)

**Objectif :** découvrir les bases de la programmation en réalisant un jeu du pendu dans une page HTML.

| Séance / activité | Description |
|---|---|
| **Variables et conditions** | Écrire des scripts JavaScript simples ; manipuler chaînes, nombres et conditions à partir de petits exercices. |
| **Boucles, tableaux et fonctions** | Choisir un mot dans une liste, parcourir ses lettres et isoler des actions dans des fonctions. |
| **Règles du pendu** | Développer la logique : lettres proposées, nombre d’erreurs, victoire et défaite ; tester les cas simples. |
| **JavaScript et DOM** | Relier la logique à la page HTML : afficher le mot masqué, les lettres jouées et les messages de jeu. |
| **Finalisation du pendu** | Ajouter une interface utilisable (boutons ou clavier), rejouer une partie et corriger les bugs en binôme. |

---

## Bloc 3 — Messagerie WebSocket : découverate et spécification (10h)

**Objectif :** comprendre la communication temps réel et commencer une interface client respectant une spécification commune.

| Séance / activité | Description |
|---|---|
| **Communication client-serveur** | Distinguer HTTP et WebSocket ; se connecter au serveur WebSocket fourni par l’enseignant et observer les messages échangés. |
| **Lire une spécification de messages** | Étudier le format imposé des messages (par exemple JSON : pseudo, contenu, type) ; envoyer et interpréter des messages de test. |
| **Maquette de messagerie personnelle** | Concevoir en HTML/CSS sa propre interface de salon de discussion ; chaque étudiant prépare un design différent compatible avec le même protocole. |

---

# Semestre 2 — Temps réel, données et PHP (environ 45 h)

## Bloc 4 — Messagerie WebSocket : réalisation et intégration (9 h)

**Objectif :** terminer une messagerie temps réel sans authentification, en connectant toutes les interfaces au serveur WebSocket commun.

| Séance / activité | Description |
|---|---|
| **Client WebSocket JavaScript** | Ouvrir et fermer une connexion, gérer les événements et afficher les messages reçus dans l’interface. |
| **Envoyer et afficher des messages** | Construire les messages selon la spécification, envoyer depuis un formulaire et afficher pseudo, contenu et heure. |
| **Test collectif et démonstration** | Connecter toutes les interfaces au même serveur ; vérifier l’interopérabilité, corriger les écarts à la spécification et présenter les choix d’UI. |

---

## Bloc 5 — Introduction à l’analyse de données avec Python (12 h)

**Objectif :** explorer un jeu de données choisi par chaque étudiant et présenter quelques résultats dans un notebook Marimo.

| Séance / activité | Description |
|---|---|
| **Choisir et lire un jeu de données** | Identifier une source de données exploitable, importer un fichier CSV dans Marimo et observer ses lignes et colonnes. |
| **Premiers pas avec Pandas** | Manipuler un DataFrame : sélectionner des colonnes, filtrer des lignes, repérer les valeurs manquantes et obtenir des statistiques simples. |
| **Regrouper et visualiser** | Réaliser un comptage ou un regroupement simple ; produire un graphique adapté avec PyChart et interpréter le résultat. |
| **Mini-compte rendu de données** | Construire un notebook Marimo clair : question posée, préparation minimale, graphique et courte conclusion. |

---

## Bloc 6 — PHP procédural typé : mini Pokédex (18 h)

**Objectif :** créer un Pokédex web simple en PHP procédural typé, puis introduire les objets à partir du domaine Pokémon.

| Séance / activité | Description |
|---|---|
| **Découvrir PHP** | Exécuter un script PHP, utiliser variables typées, conditions et boucles ; afficher des informations sur un Pokémon. |
| **Tableaux et fonctions** | Représenter une petite liste de Pokémon avec des tableaux ; écrire des fonctions typées pour rechercher et afficher une fiche. |
| **Pages dynamiques et paramètres** | Construire une liste et une page détail ; utiliser des paramètres d’URL de façon contrôlée. |
| **Formulaires et filtrage** | Ajouter une recherche ou un filtre par type ; lire et valider simplement les données envoyées par un formulaire. |
| **Première classe `Pokemon`** | Transformer progressivement un tableau en objet ; introduire classe, propriétés, constructeur et méthode d’affichage. |
| **Atelier Pokédex et bilan** | Finaliser le Pokédex, comparer approche procédurale et objet, corriger le projet et présenter les choix réalisés. |

---

## Bloc 7 — Consolidation et présentation (6 h)

**Objectif :** consolider les acquis de l’année et valoriser les réalisations.

| Séance / activité | Description |
|---|---|
| **Atelier de reprise** | Reprendre une difficulté identifiée dans les projets (HTML/CSS, JavaScript, Pandas ou PHP) et la corriger avec un accompagnement ciblé. |
| **Présentation de fin d’année** | Présenter un ou plusieurs projets, expliquer les choix techniques et effectuer un bilan personnel des compétences acquises. |

---

## Évaluation et suivi

- **Évaluation formative continue :** exercices courts, vérification de compréhension en début/fin de séance et corrections collectives.
- **Jalons :** portfolio/CV, jeu du pendu, messagerie WebSocket compatible avec le serveur commun, notebook d’analyse de données et Pokédex PHP.
- **Critères récurrents :** fonctionnement, lisibilité, respect des consignes et de la spécification, qualité de l’interface, capacité à tester et à expliquer ses choix.
